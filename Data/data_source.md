## Data Source

All data was downloaded from the **U.S. Department of Education's College Scorecard**.
This can be downloaded at: https://collegescorecard.ed.gov/data/.

### Data Columns

This data source has many columns, most of which are not usable for this project. The full data dictionary can be found in `Data/CollegeScorecardDataDictionary.xlsx`. This dictionary can also be downloaded at: https://collegescorecard.ed.gov/data/data-documentation/.

The columns chosen for this project are outlined below.

**Institutions:**
* unit_id
* school name
* state
* region code
* locale code
* net price (public and private)
* graduation rate
* undergrad size

**Field of Study:**
* unit_id
* school name
* major code
* major name
* credential level
* median earnings after 1 year
* median federal debt
